# Sweep of 2026-11-12 (night): what was looked at, what is left

An unattended pass over three things: the code written since the audit of 2026-11-10 (140 commits, an adversarial review),
the user's play logs of 2026-11-11 and 11-12 (18 MB), and how the mod survives a game patch and its own update. What was
fixed is in the commits of that night and in the documents they touch; this is the list of what was found and **left for
the owner**, each with its evidence and the choice it needs. Nothing here was changed.

## The mod's own update

| Found | Evidence | What it needs |
|---|---|---|
| Files of an older version stay | `PackageInstall.Replace` walks the new package only; a file a release drops (a plugin dll, a catalog) is left and may be loaded | a list of the package's files shipped with it, and the last list's files no longer listed removed |
| No way back from a release that installs and does not start | the backup is deleted with the work folder once the copy is done (`Updater`) | the last version kept beside the new one and taken back after N failed starts; or the release script starting the package once before publishing |
| The download is checked, not signed | the SHA-256 comes from `release.json` of the same release; the `.7z` has no hash; `Publish-Release.ps1` does not download what it published to compare | a signature with a key the launcher holds; the script's own check |
| A failed zenity or kdialog is taken as "No" | `HostDialog.Answer` maps any exit code but 0 to No (a tested choice of the Linux port) | falling back to the message box for codes other than 0 and 1, if a Linux player reports a silent start |
